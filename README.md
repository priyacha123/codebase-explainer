# CodeBase Explainer Tool

> An Agentic AI system that helps developers quickly understand unfamiliar codebases by visualizing structure, mapping dependencies, and generating AI-powered explanations.
> 

---

## 🧩 Problem Statement

When working on new or large projects, developers find it difficult to understand the codebase and identify where to begin. Current solutions do not provide a clear overview of how files are connected or how the system flows. This creates a barrier for learning and contributing.

This tool simplifies codebase understanding by showing structure, relationships, and guided navigation — powered by an AI agent.

---

## ✨ Features

- 🔗 **GitHub URL input** — paste any public repo URL to analyze it instantly
- 📁 **File Upload** — upload a local codebase as a zip file
- 🌳 **File Tree Viewer** — visual breakdown of the repository structure
- 🕸️ **Dependency Graph** — interactive visualization of how files are connected
- 🤖 **AI-Powered Explanations** — per-file summaries generated by an LLM agent
- 🧠 **Agentic Reasoning** — the agent breaks down the goal, plans steps, and executes analysis
- 🛠️ **Prompt Editor UI** — inspect and modify agent prompts directly from the interface (no hidden prompts)

## 🚀 Getting Started

### Prerequisites

- Node.js >= 18 or Python >= 3.10
- Git
- An OpenAI or Gemini API key

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/codebase-explainer-tool.git
cd codebase-explainer-tool
```

### 2. Set up environment variables

Create a `.env` file in the root (never commit this file):

```bash
# .env
LLM_API_KEY=your_openai_or_gemini_key
GITHUB_TOKEN=your_github_personal_access_token
PORT=8000
```

### 3. Install backend dependencies

```bash
# Python (FastAPI)
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

```bash
# OR Node.js
cd backend
npm install
npm run dev
```

### 4. Install frontend dependencies

```bash
cd frontend
npm install
npm run dev
```

### 5. Open the app

Visit `http://localhost:3000` in your browser.

## 🤖 How the Agent Works

1. **Input** — User provides a GitHub repo URL or uploads files
2. **Ingestion** — Backend fetches repo contents via GitHub API or file upload
3. **Parsing** — Code parser extracts file structure, imports, and dependencies
4. **Graph Building** — Dependency graph is constructed from parsed relationships
5. **Agent Planning** — AI agent receives the file list and plans which files to explain first (entry points, core modules)
6. **Execution** — Agent sends each file to the LLM with context about its dependencies and gets a structured explanation
7. **Output** — Frontend renders the file tree, dependency graph, and per-file explanations

> All prompts used by the agent are stored in `config/prompts.json` and can be edited via the **Prompt Editor UI** in the app.
